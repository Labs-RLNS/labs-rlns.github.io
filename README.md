# Austin Rolens

This repository is the website at https://labs-rlns.github.io, published with GitHub Pages.

It is managed with the Control Panel on Austin Rolens’s computer. Each publish is one commit, so the full history of the site is kept here.

- `content.json` holds every published project, creative piece and question.
- The HTML pages, `sitemap.xml` and `feed.xml` are generated from it on every publish.
- `media/` holds uploaded images and files.
- `assets/custom.css` is for your own style changes. The Control Panel never overwrites it.
- `assets/site.css`, `assets/site.js` and `assets/render.js` are the design. The Control Panel only replaces them when it installs a newer design.
